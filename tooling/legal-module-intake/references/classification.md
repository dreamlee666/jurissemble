# Classification guide

Choose the module type by its primary output, not by practice area.

| Type | Primary output | Default limit |
|---|---|---|
| `SOURCE_CHECK` | source status, history, authority check | requires authoritative sources and an as-of date |
| `RULE_DECISION` | intermediate rule-application result | must state exceptions and human escalation |
| `RESEARCH_ANALYSIS` | sourced research matrix or disagreement map | is not final matter advice |
| `EVIDENCE` | proof target, evidence need, gap or linkage matrix | does not decide authenticity or admissibility |
| `DOCUMENT_CLAUSE` | document structure, clause or variable draft | output remains a draft |
| `PROCESS` | steps, roles, branches and checkpoints | completion does not guarantee substantive success |
| `ARGUMENT_PATTERN` | claim, authority, counterargument and response structure | requires matter facts and strategic choice |
| `COMPOSITION` | connections and handoffs among modules | preserves each child module's source and responsibility |

Modularity is a risk boundary, not a quality score:

- `HIGH`: the output is narrow, typed, independently checkable, and has limited contextual judgment.
- `MEDIUM`: the method is reusable but issue framing, search strategy, or interpretation requires professional judgment.
- `LOW`: the value lies mainly in a decision or advocacy framework; outputs cannot be used without matter facts and a responsible lawyer.

Prefer the smallest useful candidate. Split candidates when they have different inputs, reviewers, source-update cycles, permissions, or stopping conditions.
