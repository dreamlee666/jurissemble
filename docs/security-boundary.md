# 安全、保密与公共发布边界

公共仓库只接受一般方法、公开来源、虚构示例和已经完成权利审查的原创内容。

## 禁止进入公共区

- 可识别客户、交易相对方、证人或员工的信息；
- 未公开合同、通信、证据、案件事实和策略；
- 律师意见、工作底稿和受保护的事项记录；
- 执业证件、身份证件、手机号和账号凭据；
- 未获授权的律所模板、商业数据库正文和第三方译文；
- 密钥、Token、Cookie、生产数据库和部署凭据。

## 发布前检查

1. `AUTHORITY`：贡献者是否有权公开；
2. `SECRECY`：是否存在保密、特权或组合推断风险；
3. `RIGHTS`：第三方版权、数据库、平台条款和个人信息是否允许；
4. `GENERALIZE`：公开的是方法与接口，而不是客户结果；
5. `SOURCE`：来源、版本、精确位置和截止时间是否完整；
6. `RESPONSIBLE_REVIEW`：是否由有权限的人确认发布。

发现问题时默认 `HOLD_PRIVATE`，而不是自动去标识后发布。
