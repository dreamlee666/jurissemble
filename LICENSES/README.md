# License map

This repository uses multiple standard licenses:

- `Apache-2.0`: software, scripts and validators. Full text: [`../LICENSE`](../LICENSE).
- `CC-BY-4.0`: original specifications, documentation, diagrams and public Legal Module examples. Canonical legal code: <https://creativecommons.org/licenses/by/4.0/legalcode>.
- `CC0-1.0`: Schema fields and foundational metadata vocabulary. Canonical legal code: <https://creativecommons.org/publicdomain/zero/1.0/legalcode>.

Third-party and official materials are excluded from these blanket grants unless the relevant file or rights manifest says otherwise. Private Project and Matter content is never covered by the public repository licenses.

Where a file contains an SPDX identifier or an adjacent rights manifest, that specific notice controls for the file.
